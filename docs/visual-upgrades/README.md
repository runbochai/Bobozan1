# 图像化升级与商城

战后奖励和补给商城使用大图卡片，只保留名称、等级 / 次数 / 血量和价格。沿用像素边框、深蓝底色和金色操作按钮。

- 为治疗、升级、全部 9 件遗物和 9 件装备提供彩色像素图案；秘技复用已有技能插画。
- 物品轻微上下浮动，点缀光晕和像素粒子，悬停卡片高亮，购买后显示短暂获得提示。系统和游戏内的减少动画设置均生效。
- 鼠标悬停或键盘聚焦可看详情；触屏点右上角 `i` 展开，再点一次或点外部关闭。Esc 收起提示，查看详情不会领取或购买。
- 升级详情包含新解锁技能的图片；限次卡详情保留次数、能量消耗和技能效果。金币不足时显示差额，不能扣款或移除商品。
- 领取仍为一次点击；奖励弹窗与商城使用原生模态对话框管理焦点和背景滚动。短屏可在弹窗内滚动。
- 修复远征的限次技能被误当作多人复仇卡、进入下一关后再次出现抽卡弹层的问题。

## 验证

82 项现有测试、TypeScript、ESLint 和生产构建通过。

Chrome 实测 1440 / 390 / 320px：完整三课、奖励领取、秘技展示、购买扣款、金币不足保护、信息按钮、Esc 和继续出战。额外用真实组件覆盖四选一、Lv.3 技能预览、鼠标移入浮层、键盘、320×480 短屏、768px 英文及系统减少动画模式。无页面异常及横向溢出。

游戏流程记录见 [validation.json](validation.json)，补充交互见 [details-validation.json](details-validation.json)。
